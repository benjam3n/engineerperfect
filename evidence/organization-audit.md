# Historical classification of the earlier information tree

This records the preceding revision. The [completion correction](completion-correction.md) replaces its information-tree organizing rule with the supplied engineering method.

The former organization treated twelve documents as terminal subjects and left their internal distinctions implicit. It also mixed project interpretations with the work itself. The correction classifies contents by their role and preserves original documents as sources. Not fitting one tree is evidence to inspect the representation; it is not enough to conclude that the material is unnecessary.

## Alternatives that were rejected and why

| Candidate correction | What it would still omit | Implemented difference |
|---|---|---|
| More headings under every existing filename | Mixed project interpretation, claim, case, and dependency roles | Classify contents and create canonical result records. |
| A single deeper technical taxonomy | Inquiry that changes purposes, values, beneficiaries, interpretation, or what becomes thinkable | Those distinctions occur in the main subjects and in a view by mental change. |
| Force each result into exactly one branch | Shared dependency, transfer, and the same result's several receiving uses | Several parents refer to one result; original source and conditions stay attached. |
| Keep adding nested levels indiscriminately | The relation that an extra level is supposed to preserve | Subdivision ends where actual conditions, consequence, and operation are explicit. |
| Put a criticism in an appendix | The producer still generates the old hierarchy | Canonical data, page generator, source access, and contributor instructions all change. |

Mindchangeresearch's organization-and-representation result requires judging which answers the representation preserves and what effort reconstruction imposes.
